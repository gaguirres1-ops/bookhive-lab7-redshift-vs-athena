# Laboratorio 7: Redshift vs Athena - Proyecto Bookhive

## Descripción del Proyecto
Este laboratorio realiza un análisis comparativo de rendimiento y arquitectura entre Amazon Redshift y Amazon Athena utilizando el conjunto de datos de Bookhive.

## Estructura del Repositorio
* `datos/`: Conjuntos de datos locales y muestras para procesamiento.
* `infra/`: Plantillas de infraestructura (Athena y Redshift).
* `sql/`: Consultas SQL para creación de tablas y análisis comparativo.
* `scripts/`: Scripts en Python/Boto3 para automatización.
* `docs/`: Documentación del laboratorio y capturas de pantalla.
